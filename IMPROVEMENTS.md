# Possible Improvements

Some improvements I'd like to make in the future:

- **More tests** – Add ViewModel and UI tests to cover loading, error, and empty states.
- **Dependency injection** – Use Hilt or Koin instead of managing dependencies manually.
- **Better error handling** – Show more specific error messages.
- **CI** – Set up GitHub Actions to automatically build the project and run tests.
- **Retry handling** – Add automatic retries with a short delay to better handle the mock API's frequent failures.
